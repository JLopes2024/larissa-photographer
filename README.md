# Larissa Photographer

Site oficial da **Larissa Photographer**, desenvolvido como portfólio fotográfico responsivo com foco em apresentação visual, performance, SEO e geração de contatos.

🔗 **Site publicado:**  
https://larissa-photographer.vercel.app

---

## Sobre o projeto

O projeto foi desenvolvido para apresentar o trabalho da fotógrafa Larissa de forma editorial, minimalista e responsiva.

O site reúne:

- Página inicial em formato de capa
- Portfólio fotográfico
- Filtros por categoria e subcategoria
- Página sobre a fotógrafa
- Página de serviços
- Cobertura fotográfica com Polaroid
- FAQ
- Página de contato
- Integração direta com WhatsApp
- Instagram e e-mail
- Menu mobile animado
- Página 404 personalizada
- SEO técnico
- Sitemap e robots.txt
- Open Graph
- Manifest
- Favicon personalizado
- Layout responsivo para desktop, tablet e mobile

## Tecnologias

O projeto foi desenvolvido utilizando:

- [Next.js](https://nextjs.org/)
- React
- TypeScript
- CSS Modules
- Next Image
- Next Font
- App Router
- Vercel

Não foram utilizadas bibliotecas de UI ou frameworks CSS externos.

---

## Tipografia

O projeto utiliza fontes carregadas através do `next/font`:

- **Cormorant Garamond** — títulos e elementos editoriais
- **Inter** — textos, menus, filtros e interface
- **Allura** — detalhes manuscritos
